Option A — MetaMask: serve this page over HTTP

This page was opened from your computer (file://). Browsers block wallet extensions on file://. Serve the page locally, then open the link below.

1. In a terminal, go to this file’s folder and run:

python3 -m http.server 8080

2. Open in your browser:

http://localhost:8080/

Option B — Private Key (.env): use the companion server.js

Create a .env file next to this HTML file:

PRIVATE_KEY=0xYOUR_PRIVATE_KEY_HERE PROXY_ADDRESS=0xYOUR_POLYMARKET_PROXY_ADDRESS

Then run (install once with npm install express dotenv cors):

node server.js

Open http://localhost:3000 — click the Private Key (.env) tab and the fields will be pre-filled automatically.
